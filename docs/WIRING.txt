[1] 水路

         ___________________
        |  PP #05 外槽       |      花盆放在裡面
        |    ___________     |
        |   |   花盆    |    |
        |   |___________|    |
        |  ~~~~~~~~~~~~~~~~  |  <- 淹水位
        |--- overflow 溢流孔 |-------------------+  在淹水位上方 1cm
        |___________________|                    |  熱螺絲起子熔穿
                  |  單一根管，出口在外槽底部     |  (PP 用 220-250C)
                  |  且必須沒入水中 —— 出口       |  接管導回水箱
                  |  露在空氣中就無法虹吸回流     |
                  v                               v  這是唯一能擋
         ______________________________________________  繼電器接點
        |  HDPE #2 水箱 (ON 900g 桶)  蓋子是 PP #05   |  燒死的保護，
        |                                             |  不可省略
        |   [泵]  <- 任何時候都必須泡在水裡           |
        |_____________________________________________|
         截面 ~143 cm2 -> 水位 1 cm = ~143 ml
         水箱必須低於外槽。泵停 = 重力虹吸回流。
         斷電 = 同樣結果。fail-safe 是結構保證的，不是靠程式。

[2] 電源與繼電器                      星狀接地：每條 GND 各自回 PSU 負極
                                      繼電器切的是 buck 的「輸出」，
                                      三顆轉換器都常時通電
   12V PSU +
      |
      +--> LM2596S #1  調 4.45V --[CH1 COM->NO]--> LED 環 x4
      |      這顆要調準，而且要「帶載調」：CH1 閉合、燈環接著，
      |      量燈環端子調到 4.45V。切輸出的好處就是隨時能重調。
      |      4.45V 是 OEM 控制器最高亮度的輸出，決定亮度也決定壽命。
      |      實測單環帶載：最暗 2.5V，最亮 4.45V / 0.35A。
      |      電壓跟著亮度走 = 燈環是電壓驅動，CV 才是控制模式。
      |      四環合計 1.4A / 6.2W，是標稱 15W x4 的十分之一。
      |      線徑和壓降在這個電流下不是問題。
      |
      +--> LM2596S #2  調 5.00V --[CH2 COM->NO]--> 泵 +  ---+
      |      只帶泵，不帶別的。不挑：泵 2.5-6V 都能跑。      |
      |      常態 0.6A；堵轉 ~2A 只是幾十 ms 的脈衝，    [M7] 色帶
      |      且低於模組內建 ~3A 限流點，不會卡住馬達。       |  朝 +
      |                                                   泵 -
      +--> RY8326  5-24V 進，5V/3A 固定輸出
      |      +--> NodeMCU VIN + 1000uF + 0.1uF
      |      +--> DHT11 VCC、HC-SR04 VCC
      |      +--> 繼電器 JD-VCC
      |      負載 ~0.5A，完全不會熱
      |
   12V PSU - ---- 共地

   切輸出而非輸入：1.4A / 0.6A 對接點微不足道，LED 也永遠碰不到
   buck 冷啟過衝（buck 一直是穩的），電壓隨時能帶載微調。
   代價是兩顆 buck 24h 通電，各約 0.1-0.3W 待機損耗，以及合閘
   瞬間輸出電容對負載的一下湧入 —— 這個電流等級無所謂。

   !! M7 在這個接法下是「必需」，不是選配。接點直接切斷馬達
      電流，反電動勢會在接點拉弧，每次點蝕一點。

   !! 兩塊 LM2596 外觀一模一樣。調好電壓當下立刻貼標籤
      「4.45 LIGHT」「5.00 PUMP」，接線前再用萬用表複驗。
      接反 = 燈吃到 5.0V，過驅 12%，而 LED 電流對電壓非線性。

   JD-VCC 接 RY8326。切輸出時兩顆 buck 都常時通電，其實接哪
   都行；但若日後改回切輸入側，JD-VCC 接到被切的那顆會死鎖：
   CH2 斷開 → buck 沒電 → JD-VCC 沒電 → CH2 自己合不起來。

   繼電器板（4-ch SRD-05VDC-SL-C，只用 2 路）

       JD-VCC o--- RY8326 5V          <- 線圈電源，常時通電
         |  x  跳線帽拔掉             <- 拔的是「帽子」，腳位要留
       VCC    o--- NodeMCU 3V3        <- 光耦輸入側。不可接 5V：
         |                               3.3V GPIO 拉高時光耦仍漏
       GND    o--- 共地                  ~0.5mA，繼電器會放不開
       IN1    o--- D3  GPIO0  燈
       IN2    o--- D6  GPIO12 泵
       10k 上拉多半不需要：IN 接的是光耦 LED 的陰極，浮空
       就是無電流 = OFF；而且這兩支腳也不會真的浮空
       （GPIO0 開機被拉高，GPIO12 重置後是 input+內部上拉）。
       先驗再決定，見下方檢查清單。
       IN3/IN4    不接

       接點一律 COM -> NO（常開），斷電即關。
       這種板子光耦兩側仍共地，所以買到的是雜訊解耦，
       不是電氣隔離。

[3] ESP 與感測器

   NodeMCU v3 (Lolin)
     VIN o--- RY8326 5V，1000uF + 0.1uF 直接並在腳上
     3V3 o--+-- HW-390 VCC        <- 走 3V3，不可 5V：5V 供電時
            |                        輸出會超過 A0 那組板上
            |                        220k/100k 分壓的 3.2V 滿刻度
            +-- SSD1306 VCC
            +-- DHT11 VCC
            +-- 繼電器板 VCC
     G   o--- 共地

     A0  o--- HW-390 AOUT
     D1  o--- SSD1306 SCL      GPIO5
     D2  o--- SSD1306 SDA      GPIO4    位址 0x3C
     D3  o--- 繼電器 IN1       GPIO0    boot 時被拉高 -> 關
     D4  o--- HC-SR04 TRIG     GPIO2    ! 已知風險，刻意接受
                                        GPIO2 是 strapping 腳，reset
                                        時必須為高。接著 HC-SR04 時
                                        esptool 進不了下載模式
                                        （No serial data received），
                                        板子也可能跑進垃圾
                                        （Fatal exception 0）。
                                        2026-09-18 二分法確認：只要
                                        拔超音波就好，IN1 和 RY8326
                                        都可以留著，而且跟感測器有沒
                                        有電無關 —— 應該是模組自己在
                                        TRIG 上有下拉。
     D5  o--- HC-SR04 ECHO     GPIO14   必須經分壓，見下
     D6  o--- 繼電器 IN2       GPIO12
     D7  o--- DHT11 DATA      GPIO13   環境溫濕度，配 10k 上拉到 3V3
                                        （模組版多半已內建）
     D0      空                GPIO16   哪天願意動線，TRIG 搬來這裡
                                        非 strapping，一勞永逸
     D8      不可使用          GPIO15   boot 時被拉低，active-low
                                        的板子會開機自鎖

   HC-SR04（5V 取自 RY8326，跟 ESP 同一條乾淨的 rail）

       ECHO ---[1k]---+--- D5     ESP8266 輸入絕對最大額定 3.6V。
                      |           這塊板只有 A0 有分壓，GPIO 一個
                    [2k]          都沒有。這是整套系統裡唯一一個
                      |           省掉就會「永久燒壞硬體」的地方。
                     GND

   HC-SR04 裝在水箱蓋「正中央」，且高出最高水位 >=5cm（盲區 2cm）。
   聲束半徑 = 距離 x 0.132：

       距離        聲束半徑   桶半徑 6.75cm    餘裕
         20 cm      2.6         6.75           4.1  ok
         40 cm      5.3         6.75           1.4  偏緊
   偏移 2cm 的話，40cm 處錐面會先碰到桶壁。壁的回波更早到，
   於是你讀到一個穩定、看起來合理、但完全錯誤的數字。
   泵和管子要推到桶壁邊，離開聲錐。
   感測器固定在「桶身上」，不要架在外部支架 —— 這樣桶被碰到
   時整組一起動，讀值不變。
   蓋子要留通氣縫，否則 100% RH 會讓探頭結霧。

   DHT11 量的是「箱內空氣」，不是水箱內部 —— 水箱頂部接近
   100% RH，超出 DHT11 的 20-90% 量程，讀值會卡住。
   擺放：遠離 LED 環（輻射熱會讓溫度偏高），也避開外槽
   正上方的蒸發氣流。

   GPIO2 風險的相處方式（不動線的前提下）
     有線燒錄   先把 HC-SR04 拔掉，燒完接回去。只需要拔這一個。
     最好       用 OTA，USB 再也不用插
     一勞永逸   哪天動線時把 TRIG 從 D4 搬到 D0 (GPIO16)

[4] 第一次通電前的檢查

   [ ] 繼電器跳線帽已拔，VCC 接 3V3，JD-VCC 接 5V
   [ ] ECHO 分壓已裝
   [ ] 繼電器板單獨通電測試：VCC→3V3、JD-VCC→5V、IN 全部懸空
       → 沒有喀噠聲、板上 LED 不亮 = 不需要上拉，直接接 ESP
       → 有繼電器吸合 = 加 10k 到 3V3，並回頭檢查 VCC 是否
         誤接 5V、跳線帽是否真的拔掉了
   [ ] M7 跨在泵上，色帶朝 +，用萬用表二極體檔驗過方向
       （切輸出側 = 接點直接切馬達電流，這顆是必需品）
   [ ] LM2596 #1 先空載粗調到 ~4.4V，接上燈環後帶載細調到 4.45V
       （量測點在燈環端子，不是 buck 輸出端）
   [ ] LM2596 #2 先空載調到 5.00V，再接泵
   [ ] 兩塊 LM2596 都貼好標籤，接線前複驗電壓
   [ ] 每顆轉換器的 GND 各自拉一條回 PSU 負極
   [ ] 插 USB 時 12V 必須拔掉（Lolin V3 沒有反灌保護）
